# NPCI — AI NPC World Server

<img width="1573" height="656" alt="NPCI_Banner" src="https://github.com/user-attachments/assets/00ed8a2a-3e61-4101-88f6-6070d920c338" />

**NPCI** turns the static pedestrians of a FiveM/ESX server into persistent, voice-capable AI characters. NPCs remember you across sessions, answer spoken or typed questions, react to their environment, send and receive SMS through the in-game phone, and can hold conversations with several players and multiple NPCs at once.

This repository is the **server-ready build** used on a production ESX server (GTA V build b3258). It is a self-contained FiveM resource — drop it in `resources/`, `ensure` it, and the database schema creates itself.

> **About this build:** the *follow / companion / NPC-driving* extras (follow-me, lead-the-way, ride-along, you-drive, race mode, flee-the-cops, land-the-aircraft) have been **removed** from this published package. Everything else — conversation, memory, voice, SMS, roleplay commands — is fully intact.

---

## What makes it different

| Feature | Typical NPC mods | NPCI |
|---|---|---|
| Conversation | Fixed dialogue trees | Free-form LLM chat (local or cloud) |
| Memory | None | Per-player, per-NPC long-term memory in MySQL |
| Voice | None | Push-to-talk STT in, neural TTS out (male/female/child/elderly/Spanish voices) |
| Phone | None | SMS conversations with the NPC from anywhere in the city |
| Consistency | Same lines every time | PedLore backstories + roles keep NPCs in character |
| Multi-NPC | Single target | Group conversations (players + several NPCs) |

## Features

- **Natural conversation** — walk up to a pedestrian, press **E**, and talk by voice (hold **N**) or type (`/t` or regular chat). Replies are generated by an LLM with the NPC's identity, role, location, weather and recent events as context.
- **Four AI providers** — defaults to **NVIDIA NIM** (free API-catalog credits, `google/diffusiongemma-26b-a4b-it`, OpenAI-compatible endpoint) with **local Ollama**, Google Gemini or OpenAI as automatic fallbacks configured through convars.
- **Persistent memory** — every NPC keeps a conversation history and a long-term summary per player (`npci_memory` table, auto-migrated on start). Meet an NPC again next week and it still remembers what you talked about.
- **Voice pipeline** — browser speech recognition in the NUI for speech-to-text, **Edge TTS** (Microsoft neural voices) for lifelike replies served by a tiny Python sidecar (`stt_sidecar.py`, port 5001) that also runs Whisper for transcription.
- **PedLore roles** — Civilian, Police, EMS, Gang, Worker, Socialite and more, each with backstory, work activities and idle activities, so NPCs behave plausibly when nobody is talking to them.
- **Living world task engine** — NPCs decide between `WANDER`, `GO_TO_WORK`, `GO_HOME`, `SCENARIO`, `STAND_GUARD`, `PATROL`, `DRIVE_TO_LOCATION` and `ESCAPE_COPS`, navigating a location database of burgershots, police stations, hospitals, gyms, beaches, bars and gang turfs.
- **Group conversations** — add a second NPC into the dialogue (default key **Y**, admin/ACE-gated) so two characters talk to each other and to you.
- **Phone bridge** — NPCs have phone numbers; texting them triggers an AI reply, and you can request a meetup: the NPC walks over to the location you asked for.
- **Roleplay command layer** — ~50 spoken phrases drive canned animations and behaviors: *hands up, sit down, kneel, dance, smoke, wave, guard this area, wait here, take a photo, beg, meditate, dismiss* and more (see the full list below).
- **Animal NPCs** — animals spawn but "don't understand you", keeping interactions believable.
- **Admin tools** — `/spawnnpc` model-picker spawner, multi-NPC ACE permission, server debug event.

## Controls

| Input | Action |
|---|---|
| **E** (rebindable) | Start / stop conversation with the targeted NPC |
| **N** (hold) | Push-to-talk to the NPC *(Admin, Associate, Elite roles)* |
| **O** | Toggle AI voice replies on/off (saved between sessions) |
| **Y** | Add the NPC you are looking at to the conversation *(admin/ACE `npci.multi`)* |
| `/t <text>` | Talk by text — reliable fallback if the chat hook is busy |
| *chat message* | Anything you type during a conversation is sent to the NPC |
| `/toggleNpcVoice` | Same as **O**, from the chat |
| `/fixlight` | Recover from a stuck timecycle modifer (screen stuck dark) |

### Spoken / typed roleplay commands

**Movement & posture:** hands up, sit down, get up, kneel, lay on the ground, crouch, lean, face me, turn around, hands behind back, wait here, stop, go over there, jog.

**Actions:** dance, push-ups, sit-ups, smoke, drink, wave, salute, use phone, take a photo, stretch, meditate, flex, point, lay on the bed, guard area, listen at the door, beg, run away.

**Roleplay:** dismiss ("you can free to go"), help me out (combat backup), taser, delete/clear, plus content-specific extras.

Removed in this package: `follow_me`, `lead_the_way`, `stop_following`, `companion`, `leave_companion`, `you_drive`, `stop_driving`, `drive_go`, `drive_stop`, `slow_down`, `escape_cops`, `lets_race`, `land_here`.

## Requirements

**Hard dependencies** (declared in `fxmanifest.lua`):

- FiveM server (FXServer, artifact 3000+; tested on artifacts ~35xxx / game build 3258)
- [es_extended](https://github.com/esx-framework/esx_core) (ESX Legacy)
- [oxmysql](https://github.com/overextended/oxmysql)
- [pma-voice](https://github.com/AvarianKnight/pma-voice)

**AI stack** (any one LLM backend + the TTS sidecar):

- **NVIDIA NIM** (recommended) — free API key from [build.nvidia.com](https://build.nvidia.com), then `set npci_nim_key "nvapi-..."` in `secrets.cfg`
- or local **Ollama** with `qwen2.5:3b` pulled — zero config, works offline
- or API keys: `set npci_gemini_key "..."` / `set npci_openai_key "sk-..."` in `secrets.cfg`
- **Python 3.9+** with `flask`, `waitress`, `openai-whisper`, `edge-tts` for `stt_sidecar.py`
- Internet access for Edge TTS synthesis (unless you swap in a local TTS)

**Database:** MySQL/MariaDB via oxmysql — the `npci_memory` table is created automatically on first start.

## Quick start

```cfg
# server.cfg
ensure oxmysql
ensure pma-voice
ensure npci_world_server
```

Full setup (AI stack, sidecar, first run): see **[INSTALL.md](INSTALL.md)**.

## How it works

```
 Player (E / N / chat / SMS)
        │
        ▼
 client/main.lua ──── interaction, phrase parsing, animations,
        │             NUI voice capture, thinking indicator
        │  HTTP 127.0.0.1:5001
        ▼
 stt_sidecar.py ───── Whisper (speech→text), Edge TTS (text→speech)
        │
        ▼
 server/main.lua ──── builds prompt (PedLore role + location + weather
        │             + telemetry + npci_memory history) → LLM
        │  NVIDIA NIM / Ollama :11434 / Gemini / OpenAI
        │  MySQL  npci_memory (history + long-term summary)
        ▼
 client renders reply (text bubble, optional neural voice)
```

`server/phone_bridge.lua` exposes the same brain to the phone network: SMS in, AI reply out, meetup requests resolved against `Config.LocationCoords`.

## Configuration

| File | Purpose |
|---|---|
| `config.lua` | Feature flags (`EnableCompanionExtras`/`EnableNpcDrivingExtras` — both **false** in this build), `LocationCoords` navigation database, `PedLore` roles, NPC chat tuning |
| `server/config.lua` | AI provider selection (`nim` / `ollama` / `gemini` / `openai`), endpoints, models; API keys read from convars, never committed |
| `npci_memory.sql` | Reference schema (authoritative migration: `server/sv_setupdatabase.lua`) |
| `secrets.cfg` (yours) | `set npci_nim_key ...`, `set npci_gemini_key ...`, `set npci_openai_key ...` |

ACE permissions:

- `npci.multi` — permission to pull extra NPCs into one conversation (granted in `server.cfg` with `add_ace`).

## Resource layout

```
npci_world_server/
├── fxmanifest.lua            # cerulean manifest + dependencies
├── config.lua                # shared config (flags, locations, PedLore)
├── npci_memory.sql           # schema reference
├── client/main.lua           # interaction, phrase engine, animations, NUI, voice
├── html/index.html           # voice capture UI (browser speech recognition)
└── server/
    ├── config.lua            # AI provider config (nim/ollama/gemini/openai)
    ├── main.lua              # prompts, LLM calls, task engine, memory, SMS AI
    ├── phone_bridge.lua      # NPC phone numbers, SMS → AI, meetups
    └── sv_setupdatabase.lua  # auto-migration for npci_memory
```
